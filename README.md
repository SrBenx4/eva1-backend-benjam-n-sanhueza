## Proyecto Django

Este proyecto contiene dos aplicaciones:

- `noticias`: rutas de inicio y contacto

## Verificación

Se pueden probar las rutas:

- http://127.0.0.1:8000/noticias/
- http://127.0.0.1:8000/noticias/contacto/
- http://127.0.0.1:8000/tienda/
- http://127.0.0.1:8000/tienda/ofertas/
